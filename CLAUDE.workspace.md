## Agent skills (heinzelwerk)

Paths are relative to the workspace folder that holds every repo checkout.

- **Workspace**: read `meta/docs/agents/heinzelwerk/workspace.md` before any team task: tickets repo, repos and roles, who calls whom, cross-repo traps.
- **Glossary**: read `meta/GLOSSARY.md` before naming anything; each repo's own `docs/agents/heinzelwerk/domain.md` lists the ADRs.
- **Learnings**: read `meta/docs/agents/heinzelwerk/learnings.md` before starting any task.

Workspace mode: follow the `heinzelwerk:team-modes` skill.
